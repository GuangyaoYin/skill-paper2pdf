## Role Of This Source

- Treat the SciSpace page as a third-party journal format/template reference for Wiley's `Journal of Geophysical Research`.
- Use it to guide the visual manuscript/PDF layout, template selection, and citation-style expectations.
- Do not treat it as the final authority for formal submission compliance. When exact requirements matter, check the current Wiley/AGU author guidelines or ask the user to provide them.

## Practical Formatting Guidance

- Use a conventional research manuscript structure: title, authors, affiliations, abstract, keywords if required, main text, acknowledgments, data/code availability, references, figure captions, tables, and supplements.
- Favor a clean, publisher-like PDF appearance with readable serif body text, consistent heading levels, conventional margins, and uncluttered figure/table placement.
- Use author-year citation behavior when the target journal or reference manager calls for JGR/Wiley-style formatting.
- Keep figures and tables close to first mention when creating a readable PDF preview; follow official submission instructions if the journal requires separate figure/table files.
- Preserve the user's scientific content and avoid changing conclusions while formatting.

## QA Checklist

- Title, author list, affiliations, abstract, headings, captions, and references are consistently styled.
- Citations and reference list style are internally consistent.
- Figures and tables are legible, numbered, captioned, and not clipped.
- Page breaks do not isolate headings, captions, or single-line paragraph fragments.
- PDF rendering has no overlapping text, missing symbols, font substitution problems, or broken equations.
